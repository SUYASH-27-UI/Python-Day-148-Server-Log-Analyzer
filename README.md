# Python Day 148 – Server Log Analyzer

## Description
A Python project that reads server log files and analyzes INFO, WARNING, and ERROR messages.

## Features
- Reads server logs from a text file.
- Counts different log types.
- Extracts error messages.
- Generates a separate text report.
- Handles missing files.

## Files
- `log_analyzer.py` – Main Python program.
- `server.log` – Sample server log data.
- `log_report.txt` – Generated report.

## How to Run
1. Keep `log_analyzer.py` and `server.log` in the same folder.
2. Run:

```bash
python log_analyzer.py
```

## Concepts Used
- Python File Handling
- Counter
- Exception Handling
- String Manipulation
- Report Generation

## Note
This project uses sample server logs for educational purposes.
